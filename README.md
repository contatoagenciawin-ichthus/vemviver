# Vem Viver

Fundação digital da Vem Viver, construída em Next.js.

## Desenvolvimento

```bash
npm install
npm run dev
```

O ambiente local do Vem Viver usa `http://localhost:3001`, preservando a porta
`3000` para o outro projeto em desenvolvimento na mesma máquina.

## Estrutura inicial

- `src/app`: páginas e estilos globais
- `src/components`: componentes reutilizáveis da marca
- `public/brand`: ativos oficiais

Esta primeira versão funciona como um Brand Lab: um ambiente navegável para validar a
fundação visual antes da expansão para site institucional, catálogo e canais comerciais.

## Referência visual

O repositório histórico `vem-viver-brandbook` é uma referência de direção de arte:
composição editorial, fundo marfim, verde profundo, tipografia serifada combinada com
sans discreta, fotografia sofisticada e movimentos suaves. A identidade atual usa a
logomarca oficial mais recente, preservada em `public/brand/vem-viver-logo.png`.
