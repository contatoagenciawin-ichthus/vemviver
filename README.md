# Vem Viver

Fundação digital da Vem Viver, construída em Next.js.

## Desenvolvimento

```bash
npm install
npm run dev
```

O ambiente local do Vem Viver usa `http://localhost:3001`, preservando a porta `3000` para o outro projeto em desenvolvimento na mesma máquina.

## Fonte única de verdade da marca

A identidade-base consolidada está na Brand Foundation v1.0.

- master oficial: `public/brand/vem-viver-logo-master.svg`
- Brand Foundation online: `/brand-lab/identidade`
- governança interna: `docs/brand-governance-v1.md`
- hub do projeto: `/apresentacao`

A master vetorial deve ser usada em toda nova aplicação. Ativos anteriores podem permanecer no repositório como histórico, mas não prevalecem sobre a versão atual.

## Estrutura do projeto

- `src/app`: páginas, Brand Lab, hub de apresentação e presença institucional
- `src/components`: componentes reutilizáveis da marca
- `public/brand`: ativos visuais e master oficial
- `docs`: documentação de governança e especificações em evolução

## Estado atual

A logomarca e a fundação visual estão consolidadas para uso institucional e digital. Estudos de rótulo permanecem conceituais.

A fase de produção gráfica ainda não foi aberta. Pantone final, perfil CMYK definitivo, substrato, faca, sangria, verniz, hot stamp, prova de cor e demais decisões de pré-impressão serão definidos apenas quando embalagem, fabricante e fornecedor gráfico estiverem confirmados.

## Rotas internas

- `/apresentacao` — acompanhamento do projeto e status das entregas
- `/brand-lab` — fundamentos e sistema visual
- `/brand-lab/identidade` — Brand Foundation v1.0
- `/brand-lab/rotulos` — estudos conceituais de rótulos
- `/site-preview` — prévia da presença institucional

As rotas de projeto são mantidas fora de indexação pública enquanto a marca estiver em implantação.
